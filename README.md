# Surprise anniversaire — Bubu 💌

Lumière → enveloppe → chibi et message → lettre → cœur d'étoiles → pétales.
HTML/CSS/JS sans dépendance (seules les polices viennent de Google Fonts).

## Personnaliser
- La lettre : constante `LETTER` en haut de `script.js` (`**mot**` = en gras rose).
- Musique : `Until I Found You.mp3` (vérifie les droits avant publication publique).

## Lancer
Ouvre `index.html`, ou `python -m http.server 8000`. Compatible GitHub Pages.
